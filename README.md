# Вход и абляция спутников: вброс алюминия в мезосферу и стратосферу

Модель входа объекта в атмосферу с расчётом **испарённой массы алюминия по высоте** —
величины, которую DRAMA/SESAM не выдаёт, потому что проектировался под casualty risk
и отслеживает выжившие фрагменты.

**Статус: шаг 4 из 6.** Есть высотное распределение испарённого алюминия.
Главный результат — **вилка**, а не одно число, и её ширина сама по себе есть
физический результат.

```
python run_step1.py       # траектория на экспоненциальной заглушке
python verify_step1.py    # проверки (кеплеров тест, сходимость, Аллен-Эггерс)
python explore_step1b.py  # диагностика: пик нагрева, свип Cd, фрагментация
python run_step2.py       # MSIS: атмосфера, траектория, свипы среды
python verify_step2.py    # проверки (сплайн, швы модели, механизм F10.7)
python run_step3.py       # нагрев, вращение Земли, бюджет неопределённостей
python verify_step3.py    # проверки (размерность k, энергия, вращение, DKR)
python run_step4.py       # фрагментация, абляция, вилка, гистограмма по высоте
python verify_step4.py    # проверки (энергобаланс, замкнутые формулы, ORSAT)
```

## Система координат и уравнения

Связанная с планетой полярная система, состояние `[V, γ, h, s]`. γ — угол наклона
траектории к местному горизонту, положительный вверх. Сферическая невращающаяся Земля.

```
dV/dt     = -(1/2)·ρ(h)·V²·Cd·A/m  -  (μ/r²)·sin γ
dγ/dt     = cos γ · ( V/r  -  μ/(r²·V) )
dh/dt     = V·sin γ
ds/dt     = V·cos γ · R⊕/r                        r = R⊕ + h
```

Выбор в пользу этой системы, а не ECI-декартовой: V и h — прямо переменные состояния,
а именно они входят в закон нагрева `q ~ √ρ(h)·V³` и в главный выход (гистограмма массы
по высоте); γ₀ задаётся как начальное условие напрямую. Цена — сингулярность при V→0,
которая нам безразлична, потому что интегрирование останавливается на ~Mach 1.

При отсутствии подъёмной силы, боковой силы и вращения Земли движение **строго
планарное** — это не приближение, а следствие допущений.

## Допущения

Разделены на три группы: обещанные в ТЗ, добавленные выбором системы координат,
и временные (снимаются на следующих шагах).

### Физика объекта

1. **Объектный уровень, без фрагментации** — временно, снимается на шаге 4.
   Это САМОЕ КРУПНОЕ допущение модели, а не одно из многих: без него главный
   результат смещён вниз на 25–30 км (см. раздел ниже).
2. **Фиксированная форма и площадь миделя, без вращения.**
3. **Сосредоточенная тепловая модель**, без градиента по толщине. *(шаг 4)*
4. **Корреляция для точки торможения применяется ко всему телу.** *(шаг 3)*
5. **Постоянный Cd.** По умолчанию 1.0, но для беспорядочно кувыркающегося
   нерегулярного тела в кодах по выживаемости обычно берут 1.4–2.0; разумнее
   считать базовым 1.5. Разброс 1.0–2.2 стоит ±5.8 км по высоте пика нагрева.
   На 120–90 км течение свободномолекулярное (Kn ≫ 1, Cd ≈ 2.0–2.2), ниже
   ~70 км континуум (Cd ≈ 0.9–1.2). По Кнудсену не интерполируем, но важна
   оговорка: торможение в свободномолекулярной зоне действительно пренебрежимо
   (`D/m ≈ 0.011 м/с²` против `g·sin γ ≈ 0.25 м/с²`), однако Cd входит и в
   континуумную фазу, где решается всё. Поэтому Cd — не безобидная константа,
   а параметр свипа.
6. **Постоянная масса** (шаги 1–3). На шаге 4 масса становится переменной состояния,
   и β = m/(Cd·A) начинает дрейфовать по ходу полёта.

### Динамика

7. **Соатмосферное вращение учтено** (шаг 3). Скорость относительно атмосферы
   `V_отн = V − ω·R⊕·cos i`. Вывод в `EntryState.corotation_speed`: атмосфера
   движется на восток со скоростью `ω·R·cos(lat)`, вдоль трассы работает её
   проекция `u·sin A`, а из сферической тригонометрии `sin A = cos i / cos(lat)`,
   поэтому **широта сокращается и остаётся только наклонение**. Проверка пределов:
   i=0 → +465 м/с, i=53 → +280, i=90 → 0, i=180 → −465 м/с.

   Остаётся **Кориолис**: `2ωV ≈ 1.1 м/с²` против `g ≈ 9.5`, то есть 11% от
   гравитации. Он направлен преимущественно поперёк плоскости траектории —
   отклоняет, а не тормозит, — поэтому на высоту и скорость влияет слабо.
   Это самое крупное оставшееся динамическое допущение.
8. **Сферическая Земля, гравитация μ/r², без J2.** J2 даёт ~10⁻³ от g за 300 с полёта.
9. **Нет подъёмной и боковой силы** → планарное движение.
10. **Нет ветра.** Атмосферная вариабельность на шаге 2 стала входными параметрами
    (дата, широта, долгота, F10.7, Ap).

    **Исправление.** В шаге 1 здесь стояло «солнечная активность меняет плотность
    на 120 км в разы». Это неверно — проверено в `verify_step2.py`. F10.7 от 70
    до 220 меняет плотность на 120 км всего в 1.07 раза. Механизм: солнечный
    нагрев управляет температурой экзосферы, а она задаёт шкалу высот в ВЕРХНЕЙ
    термосфере; на 120 км атмосфера ещё определяется мезосферой снизу.
    Чувствительность растёт с высотой: ×1.07 на 120 км, ×2.2 на 200 км,
    ×15 на 400 км.

### Атмосфера

11. **NRLMSIS 2.1 через `pymsis`** (базовая), затабулированная и сплайненная.
    NRLMSISE-00 сохранён переключаемым — см. «Почему базовая 2.1, а не 00».
    Экспоненциальная заглушка оставлена как эталон и для Аллена–Эггерса.
12. **Профиль замораживается на момент входа.** MSIS считается один раз на
    вертикальной сетке для фиксированных даты/широты/долготы, дальше траектория
    идёт по этому профилю. За 300 с полёта и 1800 км дальности объект пересекает
    ~16° по широте, где плотность на 70 км меняется на единицы процентов —
    меньше собственной неопределённости MSIS.

## Проверки

### `verify_step1.py`

1. **Кеплеров тест.** Сопротивление выключается, удельная энергия `V²/2 − μ/r` и
   удельный момент импульса `V·r·cos γ` должны сохраняться. Дрейф ~1e-15, то есть
   на уровне машинной точности — правая часть ОДУ согласована.
2. **Сходимость.** rtol от 1e-6 до 1e-12, max_step от 5 до 0.25 с: высота пика
   торможения 45.322 км во всех случаях.
3. **Аллен–Эггерс** (NACA TR-1381, 1958) — три аналитические цели, см. ниже.
4. **Чувствительность к β** — проверка предсказания `h* ∝ H·ln β`.

### `verify_step3.py`

1. **Размерность константы Саттона–Грейвса** — по измеренному пику Stardust.
2. **Энергетическая вменяемость** — поглощённое тепло против кинетической энергии.
3. **Вращение Земли** — предельные случаи по наклонению; i=90° обязано в точности
   совпасть с выключенным вращением (тест самосогласованности).
4. **Саттон–Грейвс против DKR** — цена показателя степени.
5. **Радиус затупления** — проверка, что Rn не двигает высоту пика вообще.

### `verify_step2.py`

1. **Точность сплайна** против прямого вызова pymsis на 20 000 высот: вдали от
   швов модели максимум 1.2e-5, медиана 3.7e-7.
2. **Швы модели** — численный поиск изломов `d²lnρ/dh²`.
3. **Сходимость по шагу табуляции** dh от 2000 до 100 м: высоты пиков совпадают
   до метра. Максимальная ошибка при этом НЕ падает монотонно, потому что упирается
   в швы модели, а не в разрешение сетки.
4. **Механизм F10.7** — проверка гипотезы про экзосферную температуру по росту
   чувствительности с высотой.
5. **Ранжирование факторов среды** по размаху высоты пика нагрева.

## Результаты шага 1

Базовый случай: m = 175 кг, Cd·A = 1.0 м², β = 175 кг/м², вход 120 км / 7500 м/с / −1.5°.

```
длительность до 30 км     303 с
дальность                 1878 км
макс. торможение          9.8 g на 45.3 км, при V = 3.9 км/с
γ в точке пика            -5.3°   (стартовали с -1.5°)
γ в конце                 -21.5°
```

**Аллен–Эггерс расходится, и это ожидаемо:**

| | численно | А-Э с γ₀ | А-Э с γ в пике |
|---|---|---|---|
| макс. торможение, g | 9.83 | 3.84 | 13.49 |
| высота пика, км | 45.32 | 54.45 | 45.49 |
| скорость в пике, м/с | 3862 | 4549 | — |

Аллен–Эггерс предполагает γ = const. У нас γ уходит от −1.5° к −5.3° к моменту пика.
Подставив фактический γ, формула высоты пика попадает в 45.49 против численных 45.32 —
то есть расходится именно допущение, а не уравнения. Формула перегрузки не чинится
подстановкой, потому что дополнительно предполагает V = V₀ в пике.

**Подтверждённые предсказания:**

- `h* ∝ H·ln β`: удвоение β опускает пик на −4.9 / −5.1 / −5.2 км против
  предсказанных `H·ln2 = 5.0 км`.
- `a_max` не зависит от β: при изменении β в 8 раз перегрузка меняется 9.54 → 9.97 g (4%).

**Неожиданный результат.** Высота пика торможения почти не зависит от угла входа
в диапазоне ТЗ:

| γ₀ | время, с | дальность, км | макс g | h пика, км |
|---|---|---|---|---|
| −1.0° | 348 | 2200 | 9.5 | 45.3 |
| −1.5° | 303 | 1878 | 9.8 | 45.3 |
| −2.0° | 268 | 1629 | 10.4 | 45.3 |
| −3.0° | 216 | 1276 | 11.8 | 45.0 |

Причина в структуре `dγ/dt = cos γ·(V/r − μ/(r²V))`. На 120 км круговая скорость
7836 м/с против входных 7500, то есть центробежный и гравитационный члены почти
сокращаются, и γ дрейфует медленно. Но к моменту, когда плотность вырастает
достаточно для торможения, гравитационный разворот уже стёр память о γ₀.

Практический вывод для шага 5: γ₀ влияет на **длительность** полёта (а значит на
полный тепловой поток и на то, успеет ли объект прогреться), но не на **высоту**
пика. Для гистограммы массы по слоям главный параметр — не угол входа, а β.

## Разрыв в 25–30 км: почему фрагментация не может ждать

Диагностика в `explore_step1b.py`.

Для целого объекта торможение пикует на 45 км, а нагрев `√ρ·V³` — на **56 км**
(при Cd=1.0). Пик нагрева выше, потому что скорость входит в третьей степени,
а плотность только в степени 1/2. Высота этого пика не зависит ни от константы
Саттона–Грейвса, ни от радиуса затупления, поэтому считается уже на шаге 1.

Наблюдения кладут разрушение спутников на **70–80 км**: ATV-1 на 74 км,
Cygnus OA6 на 70 км, Cluster II (SALSA) на 80 км. Настройки SESAM по умолчанию —
отрыв панелей 95 км, разрушение корпуса 78 км.

Разрыв 25–30 км. Cd его не закрывает:

| Cd | β, кг/м² | h торможения, км | h нагрева, км |
|---|---|---|---|
| 1.0 | 175 | 45.3 | 56.4 |
| 1.5 | 117 | 48.3 | 59.4 |
| 2.2 | 80 | 51.0 | 62.2 |

Весь разброс по Cd от 1.0 до 2.2 стоит 5.8 км — впятеро меньше разрыва.

Закрывает фрагментация. При геометрически подобном дроблении `m ~ L³`, `A ~ L²`,
значит `β ~ L`, а по установленному на шаге 1 закону `h* ∝ H·ln β` падение β
поднимает пик:

| β осколка | h нагрева, км |
|---|---|
| 117 (целый) | 59.4 |
| 58 | 64.9 |
| 23 | 72.5 |
| ≤12 | 78.0 — **пик на самой высоте разрушения** |

**Ниже β ≈ 20 кг/м² зависимость насыщается.** Причина: `q` зависит только от ρ и V,
а в момент разрушения они одинаковы у всех осколков. Лёгкий осколок тормозится
быстрее, чем растёт плотность, поэтому его поток монотонно падает от точки
разрушения. Для лёгких фрагментов высоту вброса задаёт **высота разрушения**,
а не β. Это делает `h_frag` главным параметром модели, а не второстепенным.

Две поправки к первоначальной оценке:

1. Чтобы пик лёг на 75 км, нужен β ≈ 17 против 117 у целого — падение в 6.7 раза.
   При равном дроблении это `N ~ 300` осколков, что многовато. Реалистичнее не
   равное дробление, а **спектр β**: панели и MLI дают 1–10 кг/м², силовой
   набор 30–80. Поэтому шаг 4 нужно строить как список фрагментов с распределением,
   а не как одно число N.
2. Пик `√ρ·V³` — это **верхняя граница** высоты вброса, а не сам вброс. Испарение
   требует накопленного тепла: прогрев до 930 K, плавление, кипение при 2740 K.
   Масса пойдёт ниже пика потока. Поэтому подгонять β так, чтобы пик потока лёг
   ровно в 70–80 км, было бы ошибкой — тогда сама масса окажется слишком низко.

## Результаты шага 2: реальная атмосфера

### Заглушка была права там, где важно

| h, км | экспонента | MSISE-00 | exp/MSIS | MSIS 2.1 / MSISE-00 | H локальная, км |
|---|---|---|---|---|---|
| 40 | 4.74e-3 | 3.83e-3 | 1.24 | 1.00 | 6.80 |
| 60 | 2.95e-4 | 2.81e-4 | 1.05 | 0.91 | 7.61 |
| 70 | 7.34e-5 | 7.05e-5 | 1.04 | 0.90 | 6.91 |
| 80 | 1.83e-5 | 1.58e-5 | 1.16 | 0.89 | 6.50 |
| 100 | 1.14e-6 | 5.40e-7 | 2.11 | 1.00 | 5.27 |
| 120 | 7.08e-8 | 1.80e-8 | 3.92 | 0.99 | 7.80 |

Локальная шкала высот на 40–120 км гуляет от **5.2 до 8.0 км** — разброс 39%
вокруг подогнанной константы 7.2 км. Заглушка попадала в 5% на 60–70 км и
ошибалась вчетверо на 120 км.

Траектория при этом почти не сдвинулась:

| атмосфера | t, с | h торможения | макс g | h нагрева |
|---|---|---|---|---|
| экспонента | 306 | 48.3 | 9.7 | 59.4 |
| NRLMSISE-00 | 305 | 47.1 | 9.1 | **59.6** |
| NRLMSIS 2.1 | 306 | 46.3 | 9.3 | 58.8 |

Сдвиг пика нагрева +0.2 км. Причина: выше 90 км, где заглушка врала в разы,
торможение пренебрежимо; в зоне 40–80 км, где всё решается, она давала 4–16%.

### Ошибка шага 1, которую нашёл шаг 2

Я дважды написал, что солнечная активность меняет плотность на 120 км в разы.
Это неверно:

| h, км | 70 | 100 | 120 | 150 | 200 | 300 | 400 |
|---|---|---|---|---|---|---|---|
| ρ(F10.7=220)/ρ(F10.7=70) | 0.99 | 0.95 | **1.07** | 1.23 | 2.18 | 6.35 | 15.2 |

Солнечный нагрев управляет температурой экзосферы, а она задаёт шкалу высот
в верхней термосфере. На 120 км атмосфера ещё определяется мезосферой снизу.
Утверждение верно для 300+ км, то есть для орбитального времени жизни, но не
для входа.

### Чем на самом деле управляется атмосферный разброс

Размах высоты пика нагрева по каждому фактору:

| фактор | размах, км |
|---|---|
| широта −75°…0° | **3.9** |
| сезон март/сентябрь | 1.6 |
| геомагнитная буря Ap 4→80 | 0.1 |
| солнечная активность F10.7 70→220 | 0.0 |
| *(для сравнения)* Cd 1.0→2.2 | 5.8 |
| *(для сравнения)* фрагментация | ~20 |

География и сезон бьют солнечную активность на два порядка — это мезосферная
температурная структура, а не термосферная. Для гистограммы это значит, что
широту точки входа надо фиксировать явно (SPOUA ≈ −40°), а F10.7 можно не
свипировать вообще.

### Швы модели

У NRLMSISE-00 рвётся производная `ln ρ` на **72.5 км** и **123.4 км** — это
внутренние границы её формулировки. Кубический сплайн их сглаживает, платя
0.1% локальной ошибки против собственной неопределённости MSIS в 10–30%.
У NRLMSIS 2.1 швов нет, профиль гладкий.

**Рекомендация: перейти на 2.1.** Два довода. Первый — 2.x переподогнан по
мезосфере и нижней термосфере, то есть ровно по нашему диапазону, и расходится
с 00 на 9–16% именно на 50–90 км. Второй — гладкость: один из швов MSISE-00
лежит на 72.5 км, прямо в зоне абляции, а адаптивный интегратор на изломах
режет шаг. По умолчанию пока стоит `version=0` (как в ТЗ); переключается
одним аргументом.

## Почему базовая 2.1, а не NRLMSISE-00

Началось с аномалии в проверке точности сплайна: два локальных всплеска ошибки
1.2e-3 против фоновых 4e-7. Оказалось, это не интерполяция — у самой NRLMSISE-00
рвётся производная `ln ρ` на **72.5 км** и **123.4 км**. У NRLMSIS 2.1 изломов нет
вообще (`verify_step2.test_model_seams`).

Причина структурная. В NRLMSISE-00 термосферные плотности считались независимо
от нижних слоёв, а профили сшивались апостериорно — этот шов и виден. В NRLMSIS 2.0
сшивку убрали: гидростатический профиль непрерывен от земли до экзосферы, переход
от перемешанной области к диффузионному разделению идёт непрерывно начиная
примерно с 70 км.

И 2.0 переподгонялась именно под наш диапазон. Emmert et al. (2021): *«In the
mesosphere and below, residual biases and standard deviations are considerably
lower than NRLMSISE-00»*; туда ассимилированы новые данные по температуре
мезосферы, стратосферы и тропосферы, атомарный кислород продлён вниз до 50 км.

Итого выбор был между моделью, у которой мезосфера — известное слабое место, и
моделью, переделанной ради мезосферы, при том что вброс решается на 50–90 км.
Один из швов 00 лежит на 72.5 км, прямо в зоне абляции, а адаптивный интегратор
на изломах режет шаг.

Довод «сопоставимость с литературой» не держится: Barker считает в GEOS-Chem,
Maloney в WACCM — у них своя метеорология, MSIS они не используют. Сопоставимость
по MSIS нужна только против инструментов демиза вроде DRAMA, для чего достаточно
переключаемого `version=0`. Разница между версиями идёт **строкой в бюджете
неопределённостей** (0.9 км по высоте), а не разовым выбором.

## Результаты шага 3: нагрев

### Размерность константы — цена ошибки четыре порядка

NASA TFAWS приводит k = 1.7415e-4 для Земли и подписывает результат Вт/см².
Прямая подстановка это опровергает. Бенчмарк Stardust (Rn = 0.23 м, V = 12.6 км/с,
ρ ≈ 3e-4 кг/м³, измеренный пик конвективного нагрева ~1200 Вт/см²):

```
q = 1.7415e-4 · sqrt(3e-4/0.23) · 12600³ = 1.258e7
   если Вт/м²  -> 1258 Вт/см²   сходится с измерением
   если Вт/см² -> мимо в 10⁴ раз
```

**k = 1.7415e-4 при входах в СИ даёт Вт/м².** Существует вариант константы
1.83e-4 (~5% выше) — держим как оценку неопределённости самой корреляции.

### Вращение Земли: широта сокращается

`V_отн = V − ω·R⊕·cos i`. Вывод — в допущении 7. Практически: для i = 53°
снос 280 м/с, это 3.7% скорости и **−9.0%** пикового потока (предсказание было
−11%). Полный размах по наклонению — 36%:

| i | v_снос, м/с | пик q, Вт/см² | Q, МДж/м² |
|---|---|---|---|
| 0° (экв. прямая) | +465 | 92.2 | 85.1 |
| 53° (типовая НОО) | +280 | 98.3 | 90.8 |
| 90° (полярная) | 0 | 108.0 | 99.9 |
| 98° (ССО) | −65 | 110.3 | 102.1 |
| 180° (обратная) | −465 | 125.3 | 116.1 |

### Горячая стенка

`q_hot = q_cold·(1 − h_w/h_0)`, где `h_0 = V²/2` — полная энтальпия торможения,
`h_w = c_p,возд·T_стенки`. Считаем по энтальпии **воздуха** у стенки, а не металла:
поток гонит разность энтальпий газа. При V = 7500 м/с и T = 2740 K множитель 0.873,
то есть −13%. Оценка по металлу (`c_p·ΔT ≈ 2.5 МДж/кг`) даёт −9% — разница между
двумя маршрутами и есть неопределённость поправки.

Поправка **растёт по мере торможения**: при V = 6100 м/с уже −19%, при 4000 м/с
−45%. У холодного конца траектории она не мала.

### Вдув продуктов абляции — нелинейность замыкается аналитически

Испаряющийся материал уходит в пограничный слой и блокирует часть потока.
Классическая линейная поправка `q_net = q_hw − η·ṁ''·h_0`, а скорость уноса сама
пропорциональна потоку, `ṁ'' = q_net/H_eff`. Подстановка даёт замкнутую форму:

```
q_net = q_hw / (1 + η·h_0/H_eff)
```

**Для архитектуры шага 4 это существенно: неявный решатель на каждом шаге
не нужен.** И закон абляции, и блокировка линейны по `ṁ''`, поэтому нелинейность
сводится к делению на множитель. Проверено против 200 итераций фиксированной
точки — совпадение до 1e-9.

При η = 0.3 (ламинарный слой; 0.6 турбулентный), `h_0 = 2.8e7`, `H_eff ~ 1.2e7`
множитель равен 0.59, то есть **вдув срезает поток на 41%**. Это не малая поправка.

### Detra–Kemp–Riddell — только как форма

Абсолютную константу DKR из надёжного первоисточника взять не удалось: в открытых
реализациях разные нормировки и показатели (3.15 против 3.25), исходная работа
1957 года в свободном доступе не нашлась. Врать константой ради красивой второй
кривой смысла нет.

Зато содержательная часть сверки от константы не зависит: вопрос в чувствительности
к **показателю по скорости**, 3.0 против 3.15. Нормируем DKR на Саттона–Грейвса
в опорной точке и сравниваем форму:

| | С–Г | DKR | разница |
|---|---|---|---|
| высота пика, км | 58.49 | 58.89 | +0.40 |
| пик потока, Вт/см² | 98.3 | 94.5 | −3.8% |
| интеграл, МДж/м² | 90.8 | 86.9 | −4.4% |

## Метрика массы: почему поток в Вт/м² не годится

Первая версия бюджета считала «массовую» ось через интегральный поток в МДж/м².
Это **ошибка знака**, а не только величины.

Масса уноса определяется полной поглощённой энергией `∫ P dt`, где
`P = φ·q_stag·A_омыв`. Для геометрически подобного тела:

```
q_stag  ~ L^(-1/2)      корреляция
A_омыв  ~ L^(+2)        геометрия
--------------------------------
P       ~ L^(+3/2)      полная мощность РАСТЁТ с размером
m       ~ L^(+3)
P/m     ~ L^(-3/2)      удельная нагрузка ПАДАЕТ с размером
```

По удельному потоку крупное тело греется слабее, по полной энергии — сильнее.
Показатели проверены численно на замороженной траектории: **+1.500 и −1.500**,
совпадение до шестого знака (`verify_step3.test_rn_scaling`).

Отсюда **второй механизм, которым фрагментация решает исход**. Осколки не просто
тормозятся выше из-за меньшего β — они ещё и получают на порядок больше тепла
на килограмм. Два независимых механизма работают в одну сторону. Самосогласованно
(когда β меняется вместе с размером) показатели становятся +2.0 и −1.0: рост β
частично гасит эффект, но знак сохраняется.

### Омываемая площадь — формула Коши, а не подгонка

Для любого **выпуклого** тела средняя по случайным ориентациям площадь проекции
равна ¼ площади поверхности. Наш `area` для кувыркающегося тела и есть средняя
проекция (её же используем в сопротивлении), поэтому

```
A_омыв = 4 · area          ТОЧНО, для любой выпуклой формы
```

Задавать вручную имеет смысл только для сильно невыпуклых тел (раскрытые панели).

### Переход от точки торможения к среднему по поверхности

Саттон–Грейвс — корреляция для точки торможения полусферического затупления,
а у нас кувыркающийся нерегулярный аппарат, у которого Rn физически не существует
и является подгоночным параметром. Стандартный обход: средний по омываемой
поверхности поток `φ·q_stag` с `φ ≈ 0.25–0.3` для случайной ориентации.
Берём 0.27. Это заодно снимает неловкость с тем, что главный параметр по массе
был неизмеряемой величиной: разброс φ стоит всего 20%, тогда как разброс
эффективного Rn — 124%.

### Структурный вывод, который важнее любой отдельной цифры

**Параметр может выпасть из одного бюджета и вернуться в другой.**

Угол входа выпал из бюджета по высоте (2.1 км — почти ничего, потому что
гравитационный разворот стирает γ₀ раньше, чем включается торможение), но
вернулся в бюджет по массе на 24%: γ₀ управляет длительностью полёта, а значит
полной поглощённой энергией.

Обратный случай — эффективный Rn: 124% по массе и **ровно ноль** по высоте,
потому что Rn константа вдоль траектории и выносится из-под argmax.

Отсюда правило для всей работы: **список ведущих параметров надо строить
отдельно для каждой выходной величины**. Единый рейтинг «что важно в этой
модели» был бы неверен независимо от того, насколько аккуратно посчитан.

## Главный результат: вилка, а не число

### Демиз в DRAMA означает расплав, а не испарение

ORSAT для generic aluminum использует **specific heat of ablation = 934.5 кДж/кг**.
Наш расчёт `c_p(T_пл − T₀) + L_пл` даёт **0.967 МДж/кг** — совпадение 3.4%.
То есть критерий демиза в ORSAT/DRAMA — это **плавление**.

Полное испарение требует **13.09 МДж/кг**. Отношение **13.5×**.

Это меняет исходную посылку проекта, а не уточняет её. DRAMA отслеживает не
выживших, а **расплавленных**. Расплавленный алюминий, сорванный сдвигом в поток,
это не Al₂O₃-наночастицы: капля может испариться дальше по траектории, может
окислиться только по поверхности и выпасть миллиметровой сферулой (так находят
абляционные сферулы метеороидов в глубоководных осадках), может застыть целиком.

Между «демизовало» и «стало наночастицами» стоит **неизвестный коэффициент
выхода**. У Ferreira он задан предположением (~20% частиц около 4 нм). Наши 13.5×
по энергии — количественная граница того, насколько сильно это предположение
может быть неверным.

### Поэтому модель выдаёт две границы

| | что это | чему отвечает |
|---|---|---|
| **верхняя** | расплавленная масса | всё, что в принципе может стать оксидом; воспроизводит критерий DRAMA — валидация |
| **нижняя** | испарённая **на месте** масса | то, что точно стало паром; вход для атмосферной химии |
| **ширина** | судьба капельной фазы | физика, которую не разрешает ни одна текущая модель |

Срыв расплава — не «другая физика, которую мы не описываем», а **причина
существования вилки**.

## Распределение вместо среднего

Испарение — задача **пороговая**, а излучение идёт как `T⁴`. В такой задаче
среднее занижает систематически: испарение идёт там, где поток выше среднего,
а среднее этого места не видит.

Поэтому поверхность разбита на пояса по углу от точки торможения, каждый со своим
энергобалансом:

```
q(θ)/q_stag = cos θ            (Ньютон + Lees, Jet Propulsion 26, 1956)
```

**Свободных параметров нет.** Альтернатива — делить тело на «носовую» и «остальную»
зоны — вводит новую неизвестную (долю площади носа), которая напрямую умножает
испарённую массу: одна неизвестная константа менялась бы на две.

Самопроверка: среднее этого распределения по полной сфере равно **ровно 1/4**,
то есть попадает в стандартную полосу форм-фактора демиз-кодов 0.25–0.30. Значит
`SHAPE_FACTOR_TUMBLING` и есть среднее *этого* распределения — новая физика не
вводится, перестаёт схлопываться имевшаяся.

Идеализация честная: для кувыркающегося нерегулярного тела осесимметричного
распределения не существует. Но идеализация без свободного параметра лучше
произвольного разбиения с параметром.

### Замкнутые формы

Локальное радиационное равновесие `εσT(θ)⁴ = q_stag·cos θ` даёт кипение там, где
`cos θ > C ≡ εσT_кип⁴/q_stag`. Отсюда аналитически:

```
доля кипящей поверхности =  (1 − C)/2
скорость испарения       =  A·q_stag·(1 − C)² / (4·L_исп)
```

Квадрат по `(1 − C)` не опечатка: у порога одновременно стремятся к нулю и площадь,
и избыток потока. Обе формулы сверены с численным интегрированием до 1e-9.

## Эмиссивность решает всё

**Поправка к первоначальному выбору.** При 1900 K излучает не окисленный *твёрдый*
алюминий, а **расплав с оксидной плёнкой** — другой материал с другим трендом:

| поверхность | ε | T, K |
|---|---|---|
| полированный Al | 0.04–0.07 | 300–900 |
| окисленный Al | 0.07–0.09 | 450–900 |
| слабо окисленный Al | 0.11–0.19 | 473–873 |
| **α-Al₂O₃** | **0.83 → 0.35** | **300 → 1800 (ПАДАЕТ)** |

У оксида эмиссивность с температурой **падает**, а не растёт — то есть тренд,
который я экстраполировал раньше, был от не того материала. Физический диапазон:
**0.05 (голый расплав) … 0.35 (сплошная плёнка оксида), фактор 7.**

Пороговый поток кипения прямо пропорционален ε, поэтому ε — **главная ось свипа**,
а не константа с оговоркой.

### Что из этого следует

Тонкая пластина 1 мм (панель, MLI), вход 120 км / 7500 м/с / −1.5°:

| ε | расплав | испарено на месте |
|---|---|---|
| 0.05 | 100% | **100%** |
| 0.10 | 98% | 81% |
| 0.15 | 94% | 49% |
| 0.20 | 81% | 28% |
| 0.30 | 39% | 6% |
| 0.35 | 13% | **2%** |

**Ответ меняется в 50 раз на физически допустимом диапазоне одной константы.**

## Два режима: энергетический и радиационный

| | целый объект (стенка 16 мм) | пластина 1 мм |
|---|---|---|
| T носа | 1550–1780 K | 2740 K (кипение) |
| расплав | 29–30% | 13–100% |
| испарено | 0% | 2–100% |
| зависимость от ε | **нет** | **решающая** |

Толстая стенка не успевает выйти на радиационное равновесие: задача
**энергетическая**, тепловая инерция решает всё, ε не влияет. Тонкая выходит
на равновесие быстро: задача **радиационная**, ε решает всё.

Критерий количественный, а не на глаз: глубина прогрева за полёт
`sqrt(α·t) = 14 см` при `α = k/(ρc_p) = 6.9e-5 м²/с`. Стенка тоньше — участвует
целиком; толще — только приповерхностный слой.

## Список фрагментов

Не N равных осколков, а спектр. Каждый фрагмент — либо **пластина** (задаётся
толщиной), либо **компактный** (задаётся β).

Для пластины β выводится из толщины и ничем больше:

```
β = m/(C_d·A_проекц) = ρ·A·t/(C_d·A/2) = 2ρt/C_d
```

(средняя проекция пластины = половина её площади, опять формула Коши).
Для Al при C_d = 1.5: t = 1 мм → β = 3.6; t = 2 мм → 7.2. Это ровно та полоса
1–10, которую дают панели и MLI в списках фрагментов — параметризация через
толщину **воспроизводит** известный диапазон, а не подгоняется под него.

Сфероэквивалент `Rn = sqrt(A/π)` для пластины неверен и даёт абсурд: панель
с β = 4 получила бы Rn = 96 см. Пластина имеет низкий β не потому, что большая,
а потому что **тонкая**.

Результат при ε = 0.10, объект 175 кг, 30% Al:

| фрагмент | m, кг | β | h разруш. | h пика q | расплав | испарено |
|---|---|---|---|---|---|---|
| солнечные панели | 17.5 | 5 | 95 км | 79.7 км | 96% | 70% |
| силовой набор | 87.5 | 55 | 78 км | 64.2 км | 30% | 0% |
| мелкие элементы, MLI | 70.0 | 4 | 78 км | 78.0 км | 96% | 40% |

```
расплавлено        110 кг (63%)  ->  32.9 кг Al   ВЕРХНЯЯ ГРАНИЦА
испарено на месте   41 кг (23%)  ->  12.2 кг Al   НИЖНЯЯ ГРАНИЦА
```

Верхняя граница воспроизводит наблюдаемую демизабельность конструкции типа
OneWeb/SpaceX (~95% для лёгких элементов), то есть модель согласована с известными
результатами по расплавленной массе. **Гистограмма пикует на 72–78 км** — внутри
наблюдаемой полосы разрушения 70–80 км, которая на шагах 1–3 оставалась
недостижимой.

## Проверки шага 4

`verify_step4.py`, все пройдены:

1. Среднее углового распределения = 0.25 **точно**.
2. Замкнутая формула скорости испарения против численного интегрирования: 1e-9.
3. Сходимость по числу поясов: разброс 0.08 п.п. при 24 поясах.
4. **Энергетический баланс**: приход = переизлучение + запас + испарение,
   невязка ~1e-16. Аудит накапливается внутри той же системы ОДУ, а не
   пересчитывается отдельно — иначе тест проверял бы копию кода.
5. Воспроизведение критерия ORSAT: 3.4%.
6. Вложенность вилки: расплав ≥ испарение всегда.
7. Применимость сосредоточенной модели по глубине прогрева.

**Что поймал энергобаланс.** Первая версия зажимала пояс на кипении симметрично,
`(1−w)·net`, запрещая ему остывать при падении прихода. Пояс излучал энергию,
которой у него не было: баланс расходился на 50%. Зажим теперь только на нагрев,
охлаждение всегда разрешено. Без этого теста ошибка прошла бы незамеченной —
все остальные величины выглядели правдоподобно.

## Открытый долг

- **Кориолис не учтён** — `2ωV ≈ 1.1 м/с²` против `g ≈ 9.5`. Направлен поперёк
  плоскости траектории, отклоняет а не тормозит. Самое крупное оставшееся
  динамическое допущение.
- **Масса станет переменной состояния** на шаге 4, β начнёт дрейфовать по полёту.
- **Константа DKR не найдена в первоисточнике** — используется только форма
  (показатель 3.15), нормированная на Саттона–Грейвса.
- **Вдув продуктов абляции** — в архитектуре шага 4, см. `heating.blowing_factor`.
  Не малая поправка: при `h_0 = 2.8e7` и `H_eff ~ 1.2e7` срезает поток на 41%.
- Профиль атмосферы заморожен на момент входа; проверено, что дрейф по широте
  за полёт стоит единицы процентов, но при свипе по широте это надо помнить.
- `allen_eggers()` сознательно принимает ρ₀ и H явными аргументами, а не тянет их
  из объекта атмосферы: обёртка над NRLMSISE-00 атрибута `rho0` иметь не будет,
  а на реальной атмосфере формула всё равно неприменима.
